# Procedencia de los recursos visuales

## Imágenes institucionales

Los siguientes archivos se obtuvieron de recursos públicos de la Universidad
de Guanajuato. Se conservan sin alterar los archivos originales, los colores ni
las proporciones. Su titularidad corresponde a la Universidad de Guanajuato.

| Archivo local | Fuente original |
|---|---|
| `escudo-ug.png` | https://ugto.mx/images/escudo-universidad-de-guanajuato.png |
| `escudo-ug-horizontal.png` | https://ugto.mx/images/escudo-horizontal-universidad-de-guanajuato.png |

Consulta de referencia: [Guía institucional de imagen](https://www.ugto.mx/imagenug).
Los emblemas no se incluyen bajo una licencia propia del proyecto.

## Gráficos del proyecto

- `abeja.svg`: ilustración vectorial original para la interfaz; no es una mascota oficial.
- `panal.svg`: patrón geométrico original.
- `campus-linea.svg`: dibujo vectorial original inspirado en arquitectura y escalinata universitaria; no es una fotografía.
- `favicon.svg`: composición original de abeja y hexágono para ReportaCampus.

Estos gráficos se editan directamente como SVG y no necesitan bibliotecas ni
servicios externos para mostrarse. Las fuentes de investigación están en
[`docs/referencias-diseno-ug.md`](../../docs/referencias-diseno-ug.md).
